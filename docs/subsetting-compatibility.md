# 子集兼容策略

本文提及的第三方字体仅用于描述兼容性现象，不随项目分发。技术验证不构成许可审查；使用者应依据具体字体许可确认使用、子集化、嵌入及分发权限。

## 收集与覆盖

文本段收集实际 Unicode 字符，以及当时生效的字体名称、字重和斜体。非空绘图段也收集字体请求：libass 的布局仍可能查询字体度量，因此不能因绘图没有文本字符而丢掉该 face。绘图坐标不会变成字符需求；未使用的样式不全量嵌入。

同一源 face 的请求合并。实际字符必须由该 face 覆盖；可选默认集合只取源字体已有的 U+0020–U+00FF、U+FF01–U+FF5E、U+3000，缺少可选字符不算错误。它覆盖常见大小写拉丁字母、数字、空格、符号及全角 ASCII，不扩展整段 CJK，也不修改字幕文字。继续保留规范组合/分解闭包、GSUB/组件闭包和 hinting。

## 旧式 AAT mort

EPSON 与 DFHanziPenW3-A 的实测差异来自源字体同时含有 `mort` 与 `GSUB`。HarfBuzz 默认子集丢掉 `mort`，使布局选择转至不同的 GSUB 路径；仅保存轮廓和水平度量不足以保真。即使 mort 只含竖排规则，删除整个表也可能影响横排路径选择。

实现读取 mort v1 非上下文替换子表（type 4），支持 lookup 0、2、4、6、8、10；保持 chain feature、flags 和 coverage。每次 HarfBuzz 布局/组件闭包后，补齐 mort 替换输出字形，迭代至稳定，再按最终 glyph ID 重建紧凑 lookup 6。源表不直接原样复制，未启用 retain-all-glyphs，也没有完整字体回退。

不支持的状态机、损坏表或无法安全编码的表返回错误；不能据此宣称所有 AAT 字体已兼容。极小字体可能因实际需求和默认集合保留全部字形，这不是错误后的整字体回退。

## 回归验证

仓库测试包含绘图字体与字重、样式重置、默认字符集合、可选缺字、实际缺字，以及合成 mort 的替换链闭包、紧凑重编号、6 种 lookup、删除标记、截断和越界拒绝。

2026-09-07 当前 Emscripten WASM 在 Deno 2.5.6（禁止子进程）处理既有成功语料 997 份。完整字体渲染作为真值，与旧正式输出的兼容对比另行记录；两种基线不可混淆。商用字体不进入仓库，详细结果保存在本次本地验证报告。此验证不涵盖此前无法处理的输入，也不证明所有播放器、字体或时间点都完全相同。
