# 以原始完整字体为基准的渲染回归

记录日期：2026-09-06。此文记录后续真实字幕测试的方案，不表示三组测试已经完成。

## 目标与对照组

主要验证子集化是否改变字幕的显示结果。以完整原始字体的渲染为基准，不把 assfonts 输出作为唯一正确答案。

| 组别 | 输入 | 作用 |
| --- | --- | --- |
| A：基准 | 预处理完成、尚未嵌入字体的 ASS，加完整原始字体 | 子集化前的渲染结果 |
| B：Rust | 同一 ASS，加 Rust 生成的字体附件 | 主要被测对象 |
| C：assfonts | 同一 ASS，加 assfonts 生成的字体附件 | 辅助判断差异来源 |

主要验收 A 与 B 一致。B 与 C 一致只能证明两种工具得到相同结果，不能排除共同问题。若 A=B、A≠C，不能仅因与旧工具不同就判定 Rust 错误；若 B=C、A≠B，应调查共同偏差。

## 输入与隔离

- 三组使用同一份已完成字体名替换、编码转换等预处理的 ASS；固定正文、样式、时间轴、PlayRes、LayoutRes 等设置。
- A 加载本案例实际使用的完整原始字体文件，保留 TTC/OTC 原始集合。记录字体 SHA-256、字体内部名称、face index、字重和斜体匹配；避免加载无关字体产生同名冲突。
- B/C 只加载各自 ASS 内的字体附件，不再提供完整字体。
- 每组使用独立的 libass Library、Renderer、Track，关闭系统字体 provider，不指定默认回退字体，不共享字体缓存。
- 各组使用同一 libass 及依赖版本、视频尺寸、像素宽高比和渲染配置。优先记录实际视频参数；模拟参数必须标注。
- 测试输入、缓存和结果置于临时目录或忽略的 `.validation/`，不修改已入库字幕；不把完整商业字体、视频或不宜再分发的字幕提交到仓库。

## 采样与比较

- 覆盖所有正时长 Dialogue 的中点，以及事件起止和前后 1ms；记录零/负时长事件。
- 对淡入淡出、移动、变换、卡拉 OK 等动态事件增加过程采样；可从每 100ms 和事件时长的 10%、25%、75%、90% 开始，针对短暂效果加密。
- 比较字幕层的预乘 RGBA，包括透明度。仅比较黑背景 RGB 可能漏掉黑字或阴影差异。
- 可先精确比较 ASS_Image 链的顺序、位置、尺寸、颜色及逐行覆盖位图；全部相同即可证明同一合成器输出相同。链不同仍应合成后比较，避免把等价绘制方式误报为视觉差异。
- 同一渲染环境默认要求零像素差，不用感知相似度掩盖偏差。记录总采样数、非空采样数、差异像素数及最大通道差，保存代表性差异帧。
- 时间采样不是所有帧的证明；对于时间相关差异，可升级为目标帧率逐帧比较。不同分辨率、渲染器版本和播放器另行验证。

## 防止误判

- 加入无附件或移除特定字体的负对照，选择确实依赖该字体的可见事件，确认测试能检测变化。
- 审计所有字体加载、选择、缺字和回退日志，不能只检查进程退出码或严重错误数量。
- A 本身选错字体或缺字时，不能把其渲染当作无条件正确。先核对来源及匹配，单独报告输入问题。
- 对只有覆盖标签、没有文字/绘图的空事件，区分字体初始化警告与实际可见缺字。libass 日志的 glyph 0x0 不必然表示字幕包含 NUL 字符。

## 可放宽与必须保留的要求

在基准渲染验证通过的覆盖范围内，不强求附件文件名、附件排序、字体子集哈希、未使用字符或名称元数据与 assfonts 逐字节一致。仍需保留字体匹配、可见字符覆盖、排版所需字形与字体表、正文/样式/时间轴不变，以及独立字体环境中的渲染回归。
