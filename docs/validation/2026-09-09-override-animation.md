## 实现与证据

主项目新增 `crates/ass/src/override_tags.rs` 作为字体分析的标签扫描层。
ass-core 继续负责段结构、样式和事件字段；不修改 fork，也不再将通用标签解析器的
完整名称/平衡括号规则等同于 libass 的扫描规则。

- 大小写敏感、有序前缀识别。全部 54 个前缀及顺序逐项对照固定 libass 0.17.5
  `ass_parse.c` 检查通过。`\border` 匹配 `\bord`，`\frzmath…` 匹配 `\frz`，
  `\blu`/`\bklur` 匹配 `\b`，不能统一忽略这些拼写。
- 括号参数在非括号参数之前切分；反斜杠参数消费至第一个 `)` 或覆盖块末尾，
  不做平衡嵌套。真正未知的标签也先消费参数，不能让其中的 `\fn` 泄漏成有效字体切换。
- `\b`、`\i`、`\p`、`\q` 的整数按十进制前缀转换，无数字时为 0，并钳制至 i32。
  字重、斜体和换行模式仍分别执行相应的样式/脚本回退规则。
- 仅允许不改变字体/状态的嵌套动画。按实际边界保留动画外的字体切换；
  迭代检查内部标签，嵌套深度限制为 64，内部 `\fn`、`\b`、`\i`、`\r`、`\p`、`\q`、`\fe` 仍拒绝。
- 所有兼容处理只影响分析视图，原始覆盖标签、颜色、动画及未知拼写均原样保留。

9 项独立 libass 状态探针通过，包含：

| 输入片段 | libass 实测状态 |
| --- | --- |
| `\b1\blu3` / `\b1\bklur4` | Bold = 0，而非保持粗体 |
| `\b1\border3` | Bold = 1，不误触发 `\b` |
| `\unknown(\fnHidden)\ZZZ(\b1)` | 不改变当前字体与字重 |
| `\t(\t(\fs40)\fnSecond` | 第一个右括号后的字体切换生效 |
| `\t(\t(\fnSecond))` | 内部会改变字体，因此分析器仍拒绝 |
| `\b(1)` / `\b1.7` | Bold = 1 |
| `\i2` | 回退当前样式的 Italic |
