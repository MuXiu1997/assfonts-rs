# 2026-09-06 本地验证

环境：macOS / Apple Silicon，Rust 1.92.0。生产 CLI 静态编译 HarfBuzz 14.4.0。测试用 libass 0.17.5 单独编译且关闭 CoreText/Fontconfig provider；测试依赖不进入 CLI。

## 自动检查

- `cargo test --workspace --locked`：16 项测试通过（含 6 项真实 CLI 集成测试）。
- `cargo fmt --all -- --check`：通过。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`：通过。
- `cargo check -p assfonts-cli --no-default-features --locked`：通过。
- `cargo build --release --locked`：通过。

覆盖：trait adapter 注入与字符合并，ASS ASCII 字体名、样式切换与恢复、绘图、软换行、transform 范围检查、BOM/CRLF 和原文保留；真实字体解析/匹配/去重/歧义/缺字；TTF glyf、OTF CFF、TTC 非零 face 子集化；CLI 批量失败、UTF-8 拒绝、覆盖保护、报告路径冲突、只读检查和输出符号链接保护。

## 链接检查

`otool -L target/release/assfonts-rs` 只有以下动态依赖：

```text
/usr/lib/libc++.1.dylib
/usr/lib/libiconv.2.dylib
/usr/lib/libSystem.B.dylib
```

可执行文件约 3.4 MB。运行不依赖 Homebrew HarfBuzz，也没有 Python、libass、FreeType 运行库依赖。

本次 release 可执行文件 SHA256：`c22cee134fc5055ad6904255ce6002f5de6bdb1756ab5b32f48f54f9fc599784`。此哈希标识本机构建产物，不承诺不同工具链/平台逐字节可复现。

使用 `tests/render/verify.py` 调用实际 release CLI，而不是原型。输入为 `tests/fixtures/cff-collection.ass`。原始字体未保存到 Git。

| 字体 | face index | 字符数 | 子集大小 |

| Expansiva OTF / CFF | 0 | 17 | 3,312 bytes |

保留所有 name 记录、legacy 名称与布局 feature，使结果比早期原型大；这是默认兼容性策略。

| 时间 | 原字体可见像素 | 嵌入结果可见像素 | 差异像素 |

PPM 图像、日志与完整处理报告保存在本地 `.validation/render-20260906/`，不纳入 Git。

## 限制

Linux musl 与 Windows 仅提供构建/CI 配置，尚未执行。WASM、其他播放器、CFF2、可变/彩色字体和大规模真实字幕库尚未专项验证。本次结果不代表原 assfonts 的全部功能或兼容性已经实现。
